# Named node types a linked tree-sitter grammar declares and no table of ours
# mentions, one `<grammar> <node type>` per line. Both ways, like the other lists:
# a type a table starts to mention must leave it, and a type a grammar release
# adds must join it (tests/node_types.rs says what a table and a mention are).
# A row is not a defect: it is a type our readers never name, so a name it
# holds is read only as text. Read the row before adding it; a type that can
# hold a declaration, a use or a path of a name is a gap to close, not to list.
# DIFFCTX_NODE_TYPES_REWRITE=1 rewrites the rows from the grammars.
