# Channel manifests

Every file here is generated by `scripts/render_packaging.py` from the release
assets — do not hand-edit; CD rewrites them on each release.

Presence of a manifest is not evidence that the channel is live:

| Directory | Status |
|---|---|
| `npm/` | Published to <https://www.npmjs.com/package/diffctx> by `publish-extras.yml` |
| `scoop/` | Manifest only — no Scoop bucket exists, so `scoop search diffctx` finds nothing |
| `aur/` | Manifest only — the repository holds no AUR credentials, and `diffctx-bin` has never been submitted to the AUR |

Support tiers, freeze rules and what promoting a manifest-only channel requires
live in the release-channel policy in
[`docs/engineering/quality-strategy.md`](../docs/engineering/quality-strategy.md).
